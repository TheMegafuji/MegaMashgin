# A short tour of Mashgin Market concept

1. **Home:** tap a floating product to add it, or use a collection to jump to a category. The header can pause motion; reduced-motion preferences are respected.
2. **Catalog:** 76 fictional products across nine categories, with eight or more in each. Original items and receipts survive additive migrations.
3. **Search:** type `cola` for instant matches. Describe a craving such as `something crunchy and salty` to ask Jev asynchronously. Arrow keys and Enter choose an option; Escape closes suggestions without deleting the query.
4. **Checkout:** confirm a fictional payment. Reload to recover the same receipt.
5. **History:** start another order, then open My orders. The API returns previous receipts for the authenticated visitor.
6. **Shared device:** open My orders and choose Forget this device to remove access to the previous guest's history.

The assortment covers packaged snacks, confectionery, wrapped bakery, cans and bottles, cups, deli, clear bowls/trays, hot food and loose/cupped fruit. Zero-alcohol drinks avoid pretending to implement age verification. There is no camera recognition claim: Mashgin's typical retail contexts informed the catalog; this is a web checkout.

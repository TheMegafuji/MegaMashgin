## Feedback

Decorative vapor is limited to warm products and is disabled by reduced-motion preferences or the motion toggle.
Nine short Web Audio motifs accompany accepted additions. Gain is conservative, playback is rate-limited and mute is persistent. Device/system volume still determines actual loudness.

## SEO and publication

Configure PUBLIC_ORIGIN with the real HTTPS origin before publishing. The server writes canonical and absolute social image URLs from that trusted configuration, never from the request Host header.
Local/HTTP execution uses noindex and a disallow-all robots file. The public sitemap includes only the market and press page. No fake review/rating, merchant address or Product structured data is emitted.
No public domain or deployment is created by generating this kit.
